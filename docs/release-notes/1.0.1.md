# Notchbee 1.0.1

## Changed

- **App icon.** Notchbee now has its own icon in Finder, the Dock and Launchpad: the notch with its glowing edge, and a bee flying out of it. The disk image shows it too.

## Install

Requires an Apple Silicon Mac with a notch and macOS 26 or later.

1. Download `Notchbee-1.0.1-2.dmg` below and drag Notchbee to Applications.
2. This build is not notarized. If macOS blocks the first launch, open **System Settings → Privacy & Security** and click **Open Anyway**.
3. Hover over the notch, open **Settings → Providers** and connect an agent.

If you already run 1.0.0, the built-in updater offers this version.
