# Notchbee 1.0.0

The first public release of Notchbee: your AI coding agents in the MacBook notch.

## Highlights

- **Sessions at a glance.** Live status for every agent in the notch, and full threads with streaming replies, work logs, plans, to-dos and diffs.
- **Start work from anywhere.** New sessions in a scratch space or any project, **Open folder…**, model switching mid-thread and provider `/` commands.
- **Approvals in the notch.** Review tool requests and accept with ⌘↵.
- **Workspace actions.** Branches, commits, pull requests and open in editor.
- **Voice on your Mac.** On-device dictation, dictation into any app (⌃⌘J) and voice commands (⌃⌥⌘V).
- **Agents.** Codex, Claude, Cursor, OpenCode, and Grok, Antigravity, Kiro, Pi, Muse and fx through the Agent Client Protocol.
- **No telemetry.** Nothing is sent to Notchbee. The Claude and Cursor SDKs download only after you agree to their terms.

## Install

Requires an Apple Silicon Mac with a notch and macOS 26 or later.

1. Download `Notchbee-1.0.0-1.dmg` below and drag Notchbee to Applications.
2. This build is not notarized. If macOS blocks the first launch, open **System Settings → Privacy & Security** and click **Open Anyway**.
3. Hover over the notch, open **Settings → Providers** and connect an agent.

Later versions install through the built-in updater.
